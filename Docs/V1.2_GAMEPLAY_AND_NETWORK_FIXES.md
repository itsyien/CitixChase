## Implementation

- IceDuration is 4.5 seconds; HUD and tests agree. Ice remains 56 m / 50-second refill.
- Relay radius is 960 cm, including the ground ring, horizontal entry/eligibility checks and instructions. One second below 60 km/h is unchanged. Exit stays 800 cm / four seconds; its marker no longer inherits relay radius.
- A reproduction of the production owner correction showed nonzero lateral speed when reconciling straight forward and reverse motion against stale yaw and a sideways position error. Position error was injected into velocity while yaw was interpolated independently. The new correction rotates predicted momentum with corrected yaw, blends server momentum in that same heading frame, and corrects position separately using a capped sweep. Genuine lateral momentum, reverse direction and vertical velocity remain. Large teleports retain the existing hard correction path. This remains bounded prediction/reconciliation, not full timestamped input replay.
- Server smoke coverage uses the same deterministic billow birth positions, growth and fade as rendering, including stationary trail puffs. No temporary arrays are allocated for coverage. At horizontal car/pawn separation below 150 m, active coverage suppresses replicated reveal state. Exactly 150 m and above restores visibility even inside smoke. There is no 180/200 m hysteresis. Leaving smoke or fading away also restores tracking.
- Chaser HUD respects reveal state for square/distance, off-screen arrow, ground direction ring and runner label. Both roles receive a concise tracking state. Ordinary round progress and escape feedback remain visible.
- Gameplay protocol 4 rejects earlier packages; both players must update.
